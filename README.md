# documents_thesis

LaTeX reports for the MIT M.Sc. thesis *Neural Reconstruction of Hidden Temperature Fields from
Sparse Observations in Turbulent Combustion* (Deng Lab).

- `main.tex` — **Month 2 Progress Report** (Overleaf main document; pdfLaTeX + BibTeX).
- `archive/month1_report.tex`, `archive/month1_report.pdf` — Month 1 report, archived unchanged
  (compile from the repository root if needed; it shares `figures/` and `references.bib`).
- `figures/month2/`, `tables/month2/` — generated by `month2_sources/make_figures.py` from the
  published result tables in `month2_sources/data/` (provenance in `month2_sources/SOURCES.md`,
  quoted numbers in `month2_sources/NUMBERS.md`).
